# Bem-vindo ao Tutorial Interativo de Engenharia de Prompt da Anthropic

## Introdução e objetivos do curso

Este curso foi desenvolvido para fornecer uma compreensão abrangente e passo a passo de como criar prompts otimizados no Claude.

**Após completar este curso, você será capaz de**:
- Dominar a estrutura básica de um bom prompt
- Reconhecer modos de falha comuns e aprender técnicas '80/20' para resolvê-los
- Entender os pontos fortes e fracos do Claude
- Construir prompts eficazes do zero para casos de uso comuns

## Estrutura e conteúdo do curso

Este curso é estruturado para permitir várias oportunidades de praticar a escrita e solução de problemas de prompts. O curso está dividido em **9 capítulos com exercícios correspondentes**, além de um apêndice com métodos ainda mais avançados. É recomendado que você **trabalhe através do curso na ordem dos capítulos**.

**Cada lição tem uma área de "Playground de Exemplos"** na parte inferior, onde você é livre para experimentar os exemplos da lição e ver por si mesmo como a alteração dos prompts pode mudar as respostas do Claude. Também há uma [chave de respostas](https://docs.google.com/spreadsheets/d/1jIxjzUWG-6xBVIa2ay6yDpLyeuOh_hR_ZB75a47KX_E/edit?usp=sharing).

Nota: Este tutorial usa nosso modelo menor, mais rápido e mais barato, Claude 3 Haiku. A Anthropic tem [dois outros modelos](https://docs.anthropic.com/claude/docs/models-overview), Claude 3 Sonnet e Claude 3 Opus, que são mais inteligentes que o Haiku, sendo o Opus o mais inteligente.

*Este tutorial também existe no [Google Sheets usando a extensão Claude for Sheets da Anthropic](https://docs.google.com/spreadsheets/d/19jzLgRruG9kjUQNKtCg1ZjdD6l6weA6qRXG5zLIAhC8/edit?usp=sharing). Recomendamos usar essa versão, pois é mais amigável.*

Quando estiver pronto para começar, vá para `01_Basic Prompt Structure` para prosseguir.
